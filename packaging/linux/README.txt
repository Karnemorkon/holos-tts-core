HolosTTS core — портативна збірка (Linux x64, без Docker)
==========================================================

1. Розпакуйте архів у будь-який каталог.
2. Один раз завантажте моделі (~0.6 ГБ):
       ./download-models.sh
3. Запустіть:
       ./holos-tts.sh
   Браузер відкриється на http://127.0.0.1:8004/ (UI: синтез + клонування).

Вимоги: Linux x64 з glibc >= 2.35 (Ubuntu 22.04+), ~2 ГБ RAM.
Сервіс слухає лише 127.0.0.1. Порт змінюється: HOLOS_PORT=9000 ./holos-tts.sh
Відкрити для LAN: HOLOS_HOST=0.0.0.0 ./holos-tts.sh (обережно: без автентифікації).

Дані:
  models/    моделі (можна перенести, задавши HOLOS_MODELS_DIR)
  speakers/  клоновані голоси (*.npy)

CLI: bin/holos-cli
Логи: stdout/stderr; зупинка — Ctrl+C.

Не клонуйте чужі голоси без згоди. Проєкт не афілійований з автором моделі.
