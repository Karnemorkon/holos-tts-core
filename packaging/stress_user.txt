# ============================================================================
# Словник наголосів користувача (stress_user.txt)
# ============================================================================
#
# Цей файл дозволяє ДОДАТИ або ВИПРАВИТИ наголоси слів БЕЗ перезбірки програми.
# Записи звідси мають перевагу над основним словником (stress.trie).
#
# Як редагувати:
#   1. Найзручніше — у веб-інтерфейсі: вкладка «Наголоси» (додавання/видалення
#      без перезапуску; цей файл оновлюється автоматично).
#   2. Або відкрийте цей файл у Блокноті (Notepad):
#      додайте слово в НОВИЙ РЯДОК у форматі:  слово+
#      ('+' ставиться одразу ПІСЛЯ голосної, на якій має бути наголос),
#      збережіть файл і перезапустіть програму.
#
# Приклади:
#   ка+ва     -> кáва
#   зам+ок    -> замóк
#   но+ги     -> нóги
#
# Правила:
#   - один запис на рядок, лише одне слово без пробілів;
#   - рядки, що починаються з '#' — коментарі (їх можна не прибирати);
#   - слово без позначки '+' буде проігноровано (у словнику користувача
#     можна лише додавати наголоси, а не прибирати їх);
#   - якщо '+' стоїть не після голосної (напр. к+ава), наголос автоматично
#     переноситься на наступну голосну (кáва);
#   - великі й малі літери, апострофи ʼ і ’ — не мають значення.
#
# Де лежить файл: поряд зі stress.trie (каталог models). Якщо файлу немає,
# працює лише основний словник. Інший шлях можна задати змінною середовища
# HOLOS_STRESS_USER.
#
# Перевірити наголос можна командою:  holos-cli stress <шлях до stress.trie> <слово>
#
# --- Приклади записів (зараз усі закоментовано; зніміть '#' перед словом,    ---
# --- щоб увімкнути його):                                                   ---
#
# кра+їна
# мо+лодь
