# Міграція на каталог 17 CC0-голосів (0.8.9)

## Коротко

Версія **0.8.9** вийшла з каталогом **29 CC0-голосів**, а 2026-11-16 його
переглянуто: чинним є **17 голосів** із перегенерованого паку
[Morkon/holos-voices-uk-cc0](https://huggingface.co/datasets/Morkon/holos-voices-uk-cc0).
Номер версії лишається **0.8.9** — це ревізія каталогу, а не новий реліз.

- було: **29** CC0-голосів у `voices.npz` / `voices.json`;
- стало: **17** CC0-голосів (12 вилучено, нових не додано);
- джерело істини — runtime-підкаталоги датасету `onnx/`, `onnx-int8/`, `mlx/`
  (`voices.npz`) і `litert/` (`voices.bin` + `holos_litert.json`);
- файли в **корені** датасету — застарілий 29-голосовий набір, їх не
  використовуйте.

Каталог однаковий у всіх форматах:

| Формат | Файл | Голосів |
|---|---|---|
| Bundle (`holos-onnx`) | `holos-onnx/voices.npz` | 17 × 256 float32 |
| Legacy (single graph) | `voices.json` (генерується з `voices.npz`) | 17 × 256 float32 |
| LiteRT | `litert/voices.bin` + `litert/holos_litert.json` | 17 × 256 float32 |

Старий каталог 29 голосів замінений, а не доповнений: 12 назв більше не
приймаються API. Це backward-incompatible зміна в межах 0.x; від 1.0.0 вона
вимагала б MAJOR-релізу.

## Чому каталог переглянуто

Пак голосів перегенеровано з референсів Mozilla Common Voice (CC0-1.0).
Частина голосів не увійшла до нової ревізії через якість референсу та
стабільність ембеддінгів, тому каталог скоротився до 17. Ваги HolosTTS
лишаються під MIT, голоси — під CC0-1.0.

Для тих, хто ще на 0.8.8: 27 службових `Speaker_*` прибрані ще в 0.8.9 з
міркувань згоди дикторів — див. розділ «Заміна `Speaker_*`» нижче.

## Як оновити клієнт

1. Отримайте актуальний список із `GET /api/voices`:

   ```bash
   curl -s http://localhost:8004/api/voices | python3 -m json.tool
   # {"voices": ["Жіноче контральто · доросле · темне", ...], "custom": [], "cloning": true}
   ```

2. Виберіть голос **за описом** і передавайте його точну назву в полі `voice`.
   Назва чутлива до регістру, пробілів і розділювача `·` (U+00B7 MIDDLE DOT).

3. Якщо був захардкоджений вилучений голос — замініть його за таблицею вище.
   Найпоширеніший випадок: `Жіноче контральто · доросле · рівне` →
   `Жіноче контральто · доросле · темне`.

4. Перевірте синтез і оновіть фікстури, якщо вони фіксують точний аудіопотік.

## OpenAI-аліаси

OpenAI-імена далі працюють, але мапляться **позиційно** на перші шість голосів
поточного каталогу (поведінка `pick_voice` у `server/src/main.cpp`):

| OpenAI `voice` | Фактичний голос |
|---|---|
| `alloy` | Жіноче контральто · доросле · темне |
| `echo` | Жіноче контральто · доросле · яскраве |
| `fable` | Жіноче мецо-сопрано · молоде · ясне |
| `onyx` | Жіноче мецо-сопрано · старше · тепле |
| `nova` | Жіноче сопрано · доросле · тепле |
| `shimmer` | Жіноче сопрано · зріле · дуже високе |

Це не семантична відповідність старим голосам, а лише сумісність із клієнтами,
які передають стандартні OpenAI-імена. Для контрольованого тембру передавайте
повну назву голосу.

## Приклади до/після

### REST `POST /api/synthesize`

Було (0.8.9 з 29 голосами):

```bash
curl -s -X POST http://localhost:8004/api/synthesize \
  -H 'Content-Type: application/json' \
  -d '{"text":"Привіт, світе!","voice":"Жіноче контральто · доросле · рівне"}'
```

Стало:

```bash
curl -s -X POST http://localhost:8004/api/synthesize \
  -H 'Content-Type: application/json' \
  -d '{"text":"Привіт, світе!","voice":"Жіноче контральто · доросле · темне"}'
```

Без `voice` сервер і далі вибирає перший голос каталогу — тепер це
`Жіноче контральто · доросле · темне`.

### OpenAI `POST /v1/audio/speech`

```bash
curl -s -X POST http://localhost:8004/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"model":"tts-1","input":"Привіт!","voice":"alloy","response_format":"wav"}' \
  -o speech.wav
```

`alloy` тепер указує на `Жіноче контральто · доросле · темне`. Для явного
тембру передавайте повну назву замість аліаса.

### WebSocket `/api/ws/synthesize`

```python
await ws.send(json.dumps({
    "text": "Привіт!",
    "voice": "Жіноче сопрано · доросле · тепле",
}))
```

### Діалог `POST /api/synthesize_dialogue`

```bash
-d '{"segments":[
  {"text":"Привіт, я Олена.","voice":"Жіноче контральто · доросле · темне"},
  {"text":"Привіт, я Іван.","voice":"Чоловічий баритон · зрілий · теплий","start_offset_ms":1200}
]}'
```

## Заміна `Speaker_*`

Старі службові `Speaker_0` … `Speaker_84` (27 голосів) прибрані ще в 0.8.9:
для них немає підтвердженої згоди дикторів
([HolosTTS discussion #5](https://huggingface.co/patriotyk/HolosTTS/discussions/5)).
Прямого відповідника 1:1 немає — вибирайте голос за статтю та характером із
таблиці 17 голосів вище. `Speaker_*` не працюють у жодному форматі.

## Оновлення Docker і портативних збірок

Каталог голосів живе в моделях, а не в образі. Починаючи з цієї ревізії
`download_models.py` **завжди** перезавантажує `voices.npz` (~21 КБ) и
переписує його рядок у `holos-onnx/SHA256SUMS`, навіть якщо решта моделей уже
наявна. Тому `--force` для оновлення каталогу не потрібен:

```bash
# Docker compose: оновити каталог у наявному volume
docker compose run --rm downloader \
  python3 scripts/download_models.py --out models

docker compose restart holos-core
```

Для портативних збірок і нативного запуску — те саме: запустіть
`download_models.py` (Linux/macOS) або `download-models.ps1` (Windows) без
`--force`. Скрипт довантажить лише відсутні файли ваг і освіжить голоси.

Перевірка після оновлення:

```bash
curl -s http://localhost:8004/healthz | python3 -m json.tool
# "voices": 17, "model_format": "bundle", "verbalizer": "neural+rule"

curl -s http://localhost:8004/api/voices
# 17 назв, "custom": []
```

Якщо в інсталяції лишився старий `voices.npz`, сервер покаже 29 голосів —
повторіть запуск downloader'а; він оновить каталог навіть без `--force`.

### Відкат

Найнадійніший спосіб — відновити бекап volume, зроблений до оновлення:

```bash
docker run --rm -v holos_core_models:/models -v "$PWD:/backup" alpine \
  tar xzf /backup/holos-models-0.8.9-29.tar.gz -C /models
docker compose restart holos-core
```

Альтернатива для bundle — тимчасово вказати старий 29-голосовий файл і вимкнути
перевірку кількості:

```bash
python3 scripts/download_models.py --out models --format bundle \
  --voices-url "https://huggingface.co/Morkon/holos-native-models/resolve/main/holos-onnx-int8/voices.npz" \
  --no-verify
```

> `--no-verify` вимикає і перевірку SHA256SUMS, і перевірку каталогу. Це
> тимчасовий захід для відкату; після нього поверніться на стандартний URL,
> щоб знову отримувати оновлення каталогу. GitHub Release `v0.8.9` містить
> актуальний 17-голосовий файл, тому для відкату він не підходить.
